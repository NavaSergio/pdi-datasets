# PDI Datasets

Repositorio de apoyo para el curso de Procesamiento Digital de Imágenes.

Aquí se concentran las imágenes originales utilizadas en ejemplos, prácticas y actividades, con el fin de que los estudiantes puedan descargarlas y reproducir los resultados mostrados en clase y en el sitio del curso.

## Contenido

- Imágenes por unidad temática.
- Archivos de apoyo para ejercicios de laboratorio.
- Conjuntos de imágenes de referencia para pruebas y comparación de resultados.

## Notas

- Este repositorio está enfocado en datos y recursos visuales; no reemplaza el material teórico del curso.
- Cuando aplique, se recomienda incluir la fuente o licencia de cada imagen.
